# Closet Try-On

A closet-aware outfit try-on built on the YouCam API. Work in progress for the YouCam API Skin AI & eCommerce VTO Hackathon.

See [docs/PLAN.md](docs/PLAN.md) for the plan.

## Run it

Requires Node 22 or newer.

```bash
npm install
cp .env.example .env   # then fill in the keys
npm run dev
```

Open http://localhost:4320.

```bash
npm test
npm run typecheck
```
